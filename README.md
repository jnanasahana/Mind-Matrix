# Grama-Yatri – Smart Rural Transportation App

## Project Overview
Grama-Yatri is an Android-based rural transportation application designed to improve connectivity and travel convenience for people living in rural areas. It helps commuters access route information, check bus timings, receive travel updates and stay informed about transportation services.

The application focuses on providing a simple and accessible travel experience with real-time data synchronisation, offline support and AI-assisted travel predictions.

## Problem Statement
People in rural areas often face difficulties accessing accurate bus timings, route information and transportation updates. Limited connectivity and a lack of reliable digital transportation services make daily commuting challenging.

Grama-Yatri aims to address these problems through a smart mobile application that provides accessible route information, travel updates and improved communication between commuters.

## Technologies Used
- **Programming Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **UI Design:** Material 3
- **Database:** Firebase Realtime Database
- **Authentication:** Firebase Authentication
- **AI Integration:** Gemini AI
- **Development Tool:** Android Studio
- **Platform:** Android

## Key Features

1. **Route Information:** Provides route details and travel information, including the Tarikere to Chikkamagaluru route.
2. **Real-Time Data Synchronisation:** Uses Firebase Realtime Database to synchronise travel information and updates.
3. **Offline Support:** Provides cached information to improve accessibility in areas with limited 2G/3G network connectivity.
4. **AI-Based Travel Predictions:** Uses Gemini AI to assist with rush and travel delay predictions.
5. **Ping and Alert System:** Helps commuters share travel-related updates and receive important notifications.

## Project Structure

The application is organised into different components for better code management and maintainability.

- **UI Components:** Jetpack Compose screens and reusable interface elements.
- **Navigation:** Handles movement between application screens.
- **Firebase:** Manages authentication and real-time database operations.
- **Maps:** Supports location and route-related information.
- **AI Integration:** Handles AI-assisted travel predictions.
- **Data Management:** Supports local caching and synchronisation.

## Installation Instructions

1. Clone the repository:

   ```bash
   git clone -b GramaYatri https://github.com/jnanasahana/Mind-Matrix.git
   ```

2. Open the cloned project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Configure your Firebase project and add the required Firebase configuration file.

5. Configure any required API credentials locally. Do not upload API keys or private credentials to GitHub.

6. Connect an Android emulator or physical Android device.

7. Build and run the application using Android Studio.
