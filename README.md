# Fuel Mileage Calculator App

## Project Overview
Fuel Mileage Calculator is an Android application developed to help users calculate and track the fuel efficiency of their vehicles. It allows users to enter fuel and distance details and understand how efficiently their vehicle uses fuel.

The application aims to make fuel mileage calculations simple, convenient and accessible through a mobile interface.

## Problem Statement
Vehicle owners often find it difficult to calculate and monitor their vehicle's fuel efficiency manually. Without proper tracking, it becomes challenging to understand fuel consumption and estimate vehicle running costs.

This application provides a simple digital solution for calculating fuel mileage and helping users monitor their vehicle's fuel efficiency.

## Key Features
1. **Fuel Entry:** Allows users to enter fuel-related information.
2. **Distance Entry:** Accepts the distance travelled by the vehicle.
3. **Mileage Calculation:** Calculates vehicle mileage using fuel consumption and distance.
4. **User-Friendly Interface:** Provides a simple interface for entering information and viewing results.
5. **Mileage Results:** Displays the calculated fuel efficiency.

## Mileage Calculation Formula

Mileage (km/litre) = Distance Travelled (km) / Fuel Consumed (litres)
